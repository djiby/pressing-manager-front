# Pressing Manager — Frontend

Interface Next.js (TypeScript) pour Pressing Manager.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Locale : `fr`
- Devise affichée : XOF

## Prérequis

- Node.js 20+ (22 LTS recommandé)
- Backend démarré sur `http://localhost:8080`

## Configuration

Créer `.env.local` :

```env
NEXT_PUBLIC_API_URL=http://localhost:8080/api/v1
```

## Démarrage

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).
